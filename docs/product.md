# Product

Yeosal helps close friend groups keep lightweight promises. A day counts when a member posts a daily goal/todo list and submits the next reflection before the following morning at 06:00.

## MVP Scope

- Email signup/login and Kakao OAuth endpoint surface.
- Today screen for goal, todo list, completion state, and reflection prompt.
- Friend group feed showing each friend's daily entry and reflection status.
- Monthly screen showing completed daily mission count.
- Profile and friend profile screens with GitHub-streak-style grass.

## Deferred

- Push notifications.
- Invite-code group rooms.
- Automated CI/CD deployment.
- Rich social reactions and comments.
