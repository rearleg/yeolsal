# Design System

## Direction

Style combines Risograph print, neobrutalist UI, punk zine collage, and retro-futurist color. The interface should feel physical: ink, paper, hard shadows, imperfect registration, and poster-like layering.

## Tokens

- `ink`: `#090909`
- `paper`: `#F8F3E7`
- `pink`: `#FF2FA3`
- `green`: `#39FF4A`
- `acid`: `#DFFF00`
- `muted`: `#9C988C`

## Components

- Buttons and cards use 3-4px black borders and 5-7px hard offset shadows.
- Primary actions use fluorescent green with black text.
- Reflection/high-emphasis actions use shocking pink with black text.
- Dark dashboard panels use deep black with high-contrast badges.
- Grain and halftone are decorative only, never the sole information carrier.

## Logo

Use `FE/assets/brand/logo.png` on login, splash, and header. Keep it inside a square safe area for app icon and splash derivatives.
